## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Grantha-Vedic-Fonts-Archive/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/Open-Typography-Foundation/Grantha-Vedic-Fonts-Archive/main/install.ps1 | iex
```
